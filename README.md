# 外卖订单预测

机器学习综合实训项目。

## 项目结构

```
.
├── data/           # 数据集
├── src/            # 源代码
├── notebooks/      # Jupyter 笔记本
├── models/         # 训练好的模型
├── reports/        # 报告与可视化
└── requirements.txt # 依赖列表
```

## 环境配置

```bash
conda create -n takeaway python=3.11
conda activate takeaway
pip install -r requirements.txt
```
